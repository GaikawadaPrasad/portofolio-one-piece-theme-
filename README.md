## ⚓ Project Overview

An authentic, manga-faithful One Piece anime-themed developer portfolio for **Prasad Gaikawada**. Engineered with pure vector art, custom Web Audio API sound synthesizers, dynamic Grand Line island navigation, and zero unicode emojis — presenting a clean, professional, and atmospheric showcase.

### 🌟 Key Highlights

- **Billion Berry Wanted Poster**: Dynamic 3D interactive Wanted Poster with sepia manga screentone texture, torn parchment borders, and official Marine HQ seal.
- **Core Engineering Disciplines**: Custom mastery gauges replacing traditional tropes with focused tracks:
  - **Full Stack Developer** (MERN architecture, REST APIs, reactive state)
  - **IoT Related** (ESP32 microcontrollers, hardware telemetry, cloud streaming)
  - **System Architecture** (Database design, reliability, performance)
- **Grand Line Archipelago (12 Conquered Projects)**:
  - Filter by category: **All Islands**, **Full Stack Web**, **IoT & Hardware**, **Mobile & AI**.
  - Featuring real production systems: *AI-Based IoT Failure Detection*, *MuscleUP Cafe Billing System*, *FinBridge Core Banking*, *Biometric Vital Health Monitor*, *Praranna Jewelleries*, *Sri Sri Associates*, *Web-Controlled Robotics*, *Melodix Android Player*, *Chat Karo*, and *InterviewMate*.
- **Devil Fruit Technical Powers**:
  - **Paramecia Class**: Frontend engineering (React, Next.js, Tailwind CSS, TypeScript).
  - **Zoan Class**: Backend & server systems (Node.js, Express, Java / Spring Boot, MongoDB).
  - **Logia Class**: Hardware, IoT & Cloud powers (ESP32, Arduino, Firebase, Docker, CI/CD).
- **Interactive Den Den Mushi Transponder**:
  - Live animated snail transponder with audio ringing (*Puru-Puru-Puru...!!*) and pickup (*Ga-cha!*).
- **Web Audio Sound Effects**:
  - In-browser synthesized sound engine (Taiko drum DON!! impact, katana slashes, berry coin chimes) with global mute control.
- **100% English & Vector Graphics**:
  - Clean English manga SFX (DON!!, DODON!!, BABAN!!) with Lucide vector icons and zero Unicode emojis.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher)
- [npm](https://www.npmjs.com/) or [pnpm](https://pnpm.io/)

### Installation

```bash
# Clone the repository
git clone https://github.com/GaikawadaPrasad/portofolio-one-piece-theme-.git

# Navigate to the project directory
cd portofolio-one-piece-theme-

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build

```bash
# Compile and optimize for production
npm run build

# Preview production build locally
npm run preview
```

## 🚢 Deploying to Vercel or GitHub Pages

### Option 1: Deploy on Vercel (Recommended)
1. Push code to GitHub (already completed).
2. Go to [vercel.com/new](https://vercel.com/new) and import `portofolio-one-piece-theme-`.
3. Framework preset: **Vite**.
4. Click **Deploy**.

### Option 2: Deploy on GitHub Pages
1. Install `gh-pages`:
   ```bash
   npm install gh-pages --save-dev
   ```
2. Add deploy script to `package.json`:
   ```json
   "scripts": {
     "predeploy": "npm run build",
     "deploy": "gh-pages -d dist"
   }
   ```
3. Run `npm run deploy`.
